# Security policy

## Supported versions

Security fixes are applied to the latest released `0.1.x` version and the `main` branch. Pre-release builds and older commits may receive a fix only through upgrading.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or leaked credential. Use the repository's private security advisory flow:

<https://github.com/therealsylva/anyapi/security/advisories/new>

Include the affected version or commit, operating system, reproduction steps, impact, and any suggested remediation. Remove live credentials and personal data from reports.

The maintainers aim to acknowledge a report within two business days, provide an initial assessment within seven business days, and coordinate disclosure after a fix is available. These are response targets, not a guarantee.

For the project's threat model and security boundaries, see [docs/security.md](docs/security.md).
